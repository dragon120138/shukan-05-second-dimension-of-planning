# 书刊5 计划的第二维度产业政策与卡尔多改善

> 学术·经济

## 关于本书

讨论计划的第二维度：在市场已配置资源的领域，计划如何通过改变相对价格与预期，引导出市场自身不会出现的卡尔多改善。以光伏、半导体、高铁与新能源车的政策史为案例主体，讨论补贴的承诺问题、退坡机制设计、以及失败政策为何难以退出。理论骨架为卡尔多改善与机制设计，案例均附可核验的政策文件与产业数据。
